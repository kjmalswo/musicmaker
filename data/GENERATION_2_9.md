# MusicMaker 2.9 수정판

- 구간 첫 비화성음을 검증할 때 직전 구간의 마지막 음과 실제 화음을 참조한다. 생성과 검증에서 같은 준비·해결 규칙을 사용한다.
- 초기 화성·합주 후보가 모두 실패하면 최대 3개의 보컬 리듬 초안을 탐색한다. 음역, 불협화음 해결, 운지, 드럼 동시타격, 악기 음역 검증을 통과한 후보만 선택한다. 반복 코러스의 핵심 훅은 유지한다.
- 장르·세부장르·분위기·반주·아티스트·색채·탑라인 감정을 시드의 설정 식별값에 반영한다. 같은 엔진 수정판·설정·시드는 같은 결과를 만든다. 이전 판의 결과와는 달라질 수 있다. JSON에 `revision: 2.9.0-r2`를 기록한다.
- 분위기 24종은 감정, 에너지, 긴장, 선율 시작 방향에 연결한다. 반주 23종 중 구체적인 연주 스타일은 악기·컴핑·보이싱을 직접 지정하며, 자동 스타일은 장르의 연주 관습을 따른다. 반주 재생도 선택 악기의 음색을 반영한다.
- 설정은 곡의 방향 → 송폼과 전개 → 키와 코드 → 보컬 → 드럼과 베이스 → 반주와 밀도로 진행한다. 각 단계에는 현재 선택 요약과 다음 단계 버튼이 있다. 드럼과 베이스는 각각 묶고, 재현 시드는 별도로 둔다.
- 설정 변경 후에는 기존 결과임을 표시한다. 생성 실패 시 이전 결과를 새 결과로 표시하지 않는다.

## 보컬 생성 프리셋

| 성부 | 생성 범위 | 중심 MIDI |
|---|---|---|
| 바리톤 | A2–A4 | 57 |
| 테너 | C3–C5 | 62 |
| 알토 | F3–F5 | 65 |
| 메조 소프라노 | A3–A5 | 69 |
| 소프라노 | C4–C6 | 74 |

이 범위는 엔진의 기본 생성 한계이며 보편적인 성부 판정 기준은 아니다. 실제 편안한 음역과 음색에 맞춰 선택한다. 기존 낮음·중간·높음 설정은 바리톤·테너·메조 소프라노로 이관한다.

성부와 편안한 음역 구분 참고: [Kansas State University](https://kstatelibraries.pressbooks.pub/vocal-techniques/chapter/identifying-voice-type/), [Berklee](https://online.berklee.edu/takenote/how-to-find-your-vocal-range-for-singing-pop-and-rb/).
